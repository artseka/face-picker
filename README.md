# สุ่มหน้า

เว็บแอปสุ่มเลือกใบหน้าจากกล้องเว็บแคม ทำงานทั้งหมดในเบราว์เซอร์ ไม่มีการอัปโหลดภาพขึ้นเซิร์ฟเวอร์ใด ๆ ใช้ [MediaPipe Tasks Vision](https://developers.google.com/mediapipe) (`FaceDetector`, โมเดล `blaze_face_short_range`) ตรวจจับใบหน้าแบบเรียลไทม์

ไฟล์เดียวจบ: `index.html` ไม่มีขั้นตอน build ไม่ต้องติดตั้งอะไรเพิ่ม

## วิธีรันบนเครื่อง

ห้ามเปิดไฟล์ผ่าน `file://` ตรง ๆ เพราะ Chrome จะบล็อกการขอสิทธิ์กล้องบน origin นั้น ให้รันเซิร์ฟเวอร์ภายในเครื่องก่อน:

```bash
python3 -m http.server 8000
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

(ถ้าใช้ Firefox จะสามารถเปิดผ่าน `file://` ได้โดยตรง แต่แนะนำให้ใช้วิธี local server เหมือนกันเพื่อความชัวร์)

## วิธีใช้งาน

1. กด "เปิดกล้อง" แล้วอนุญาตสิทธิ์กล้อง
2. รอจนโมเดลตรวจจับใบหน้าโหลดเสร็จ (ครั้งแรกจะโหลดจากอินเทอร์เน็ต)
3. เมื่อกรอบสีฟ้าล้อมใบหน้าปรากฏ กด **Space** หรือปุ่ม "🎲 สุ่ม" เพื่อเริ่มสุ่ม
4. กรอบจะสลับไปมาระหว่างใบหน้าต่าง ๆ พร้อมเสียง แล้วค่อย ๆ ช้าลงจนหยุดที่คนที่ถูกเลือก (กรอบเขียว ข้อความ "ตกลงแล้ว!")
5. กด **R** หรือปุ่ม "ล้าง/รีเซ็ต" เพื่อเริ่มรอบใหม่ หรือ **Esc** เพื่อยกเลิก/ปิดกล้อง
6. กดปุ่ม ⛶ ที่มุมขวาบนของภาพ (หรือกด **F**) เพื่อดูแบบเต็มจอ

### การตั้งค่า

เปิดแผง "⚙️ ตั้งค่า" เพื่อ:

- ใส่รายชื่อผู้เข้าร่วม (ไม่บังคับ) — ถ้าใส่ไว้ ผลสุ่มจะแสดงชื่อแทน "หน้า #N"
- ปรับความไวการตรวจจับใบหน้า (`minDetectionConfidence`)
- เปิด/ปิดโหมด "ไม่สุ่มซ้ำคนเดิม" จนกว่าจะครบทุกคนในเฟรม
- เปิด/ปิดเสียง
- เปิด/ปิดการแสดงกรอบใบหน้าทั้งหมดขณะไม่ได้สุ่ม
- ล้างประวัติคนที่เคยถูกสุ่ม

## ปัญหาที่พบบ่อย

- **ขอสิทธิ์กล้องไม่ได้ / ไม่มี prompt ขึ้น** — ต้องเปิดผ่าน `http://localhost` หรือ HTTPS เท่านั้น (ดูหัวข้อ "วิธีรันบนเครื่อง")
- **โหลดโมเดลไม่ขึ้น** — ต้องมีอินเทอร์เน็ตเพื่อโหลดไฟล์โมเดลจาก Google/jsDelivr ในครั้งแรก
- **กรอบไม่ตรงกับใบหน้า** — ลองปรับค่าความไวในหน้าตั้งค่า หรือเช็คแสงในห้อง

## รันด้วย Docker

```bash
docker build -t face-picker .
docker run -d --name face-picker -p 8080:80 face-picker
```

แล้วเปิด `http://localhost:8080` (เป็น `localhost` จึงยังนับเป็น secure context ขอสิทธิ์กล้องได้ตามปกติ)

หยุด/ลบ container:

```bash
docker rm -f face-picker
```

## Deploy ขึ้น GitHub Pages

```bash
git init
git add .
git commit -m "สุ่มหน้าออกคำสั่ง"
gh repo create face-picker --public --source=. --push
gh api -X POST repos/:owner/face-picker/pages -f "source[branch]=main" -f "source[path]=/"
```

รอสักครู่แล้วเข้าที่ `https://<ชื่อผู้ใช้>.github.io/face-picker`

หากยังไม่มี `gh` ให้อัปโหลดโค้ดขึ้นหน้าเว็บ GitHub เอง แล้วเปิด Pages จาก Settings แทน

อัปเดตล่าสุด: เชื่อมต่อ Netlify auto-deploy จาก GitHub แล้ว
